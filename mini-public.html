Create Public Mini League

Create a public Dream Team Mini League that any ScoreCast24 player can join.

How Public Leagues Work

Public Mini Leagues are visible to every ScoreCast24 user. Anyone can join until all available places have been filled.

Creating a league costs £1 and includes space for 20 players.

Joining an existing public league is free.

If the league reaches capacity, any existing member can purchase an additional 10 places for £1.

Choose a Good League Name

Choose a clear name so players know exactly what your league is intended for.

Examples

  • Liverpool FC Supporters
  • Manchester United Fans
  • NHS Staff Fantasy League
  • Teachers League
  • Football Banter League
  • Five-a-Side Friends

Before You Create

  • The league begins with space for 20 players.
  • Joining an existing public league is free.
  • The league name must not contain offensive or abusive language.
  • Any logged-in ScoreCast24 user will be able to find and join the league.
  • The creator does not need to approve new members.
  • Dream Team scoring is identical to the main weekly competition.
  • The standard ScoreCast24 Rules and Terms apply.
